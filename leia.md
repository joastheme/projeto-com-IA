# projeto-com-IA
Este é um projeto que simula o "Vibe coding" ao seu máximo. O projeto em questão é um trabalho de PW1 do professor Regilan Meira.

Prompts utilizados:

//Para o site como um todo foi-se utilizado:

*Eu - "Chat gpt, construa uma landing page utilizando apenas Html e CSS para fazer um site que fale sobre o uso consciente da energia elétrica. Utilize tabelas com table; vídeos, áudios, e um menu de navegação funcional utilizando a tag "a". Sobre a estrutura do site: Em html, utilize as tags semânticas para melhor organização. No CSS, utilize uma estilização interativa como fontes, sombras e animações com hover. Para finalizar, em nenhum momento use nada alêm de HTML e CSS.*"

O chat, todavia, não compreendeu a não utilização de keyframes e ademais para as animações que deveriam ser limitadas a "Hover" e então eu tive que fazer as correções a seguir:

*Eu - "gostaria de um css sem keyframes complexos somente utilizando hover para animações"*

Porem, o chat continuou utilizando "transform", oque me obrigou a fazer outro comando:

*Eu - "sem transition, uso de efeitos :hover em links, botões e cards."*

E então fomos capazes de adquirir o resultado experado do site que pode ser encontrado em: https://joastheme.github.io/projeto-com-IA/

Considerações finais:

Apesar de uma ferramenta extremamente potente ela tem limitações de pensamento tornando sua autonomia quasse impossível uma vez que alucinações são um tanto usuais, principalmente em planos gratuitos das inteligencias artificias. Sem deixar de destacar que embora bonito, o site tem um cara um tanto genérica e sem vida, oque normalmente não engaja o usuário a voltar a visitar. Portanto, a ferramenta é uma auxiliar muito grande ao potencial humano, mas incapaz de substituir a autenticidade que os seres viventes tem.
